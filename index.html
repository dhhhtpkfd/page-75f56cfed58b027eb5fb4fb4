使用场景

跨境协作与资料

远程会议、代码仓库、设计稿同步和学术数据库访问时，选择延迟更低的邻近节点，并开启规则模式，让国内站点直连。

流媒体与内容库

基础版覆盖常见基础流媒体解锁；旗舰版与团队版走全节点原生策略，减少片源地区限制。若单节点失败，切换同区域备用线路即可。

游戏与实时通话

旗舰版含 IPLC 专线游戏加速优化，适合对抖动敏感的对战与语音。团队版在此基础上提供更高带宽的 VIP 节点，供多人同时在线。

操作说明

  1. 在本页确认套餐配额、设备数与线路类型，完成开通后进入用户中心复制订阅地址。
  2. 按设备打开「客户端选择」对应工具，完成官方下载与安装，授予必要的代理权限。
  3. 在客户端中选择从 URL 导入或扫码导入，粘贴超平和Busters 订阅链接并更新。
  4. 开启规则模式，测试连通性；流媒体优先同区域原生节点，游戏优先 IPLC 分组。
  5. 若无法连接，先更换节点，再检查系统时间、核心版本与是否超出同时在线设备数。

订阅更新频率建议保持默认。更换套餐后旧链接可能延迟生效，以用户中心最新地址为准。

线路与性能说明

普通线路节点池覆盖港、日、新、美等常用区域，满足网页与协作软件。旗舰版增加 IPLC 专线分组，用于游戏与实时音视频。团队版另开 VIP 高带宽入口，并可按企业网段做定制分流。

高峰期请避免所有设备挤占同一入口。基础版适合轻量浏览；持续 4K 或多开下载请直接选择旗舰或团队方案，以免触发极速流量耗尽后的降速。

常见问题

超平和Busters 官方网站如何确认？

您当前浏览的即为超平和Busters 官方网站页面，用于公布套餐、客户端下载指引与操作说明。请收藏本页入口，不要从不明转发渠道填写订阅信息。

客户端下载后怎样导入机场订阅？

安装推荐客户端后，选择「订阅 / 配置 URL」，粘贴用户中心的订阅地址并更新节点。Windows 与 macOS 建议开启系统代理；移动端按应用分流可减少耗电。

三个套餐分别适合谁？

基础版面向单人轻度使用；旗舰版适合多设备、流媒体与游戏加速；团队版面向工作室或需要 20 台同时在线、定制路由与专属对接的组织。

提示设备超限或流量用尽怎么办？

同时在线超过套餐上限时，最早建立的连接可能被顶替。当月极速流量用尽后速度会下降。可下线闲置设备、等待重置或升级到旗舰版、团队版。

是否保证所有流媒体平台可用？

基础版提供基础流媒体解锁；旗舰版与团队版为全节点原生策略。片源受版权分区与平台风控影响，遇失败时切换同区域节点或更换客户端 DNS 设置。

年付与工单支持如何理解？

年付价格为基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年。旗舰版含 7x24 优先工单，团队版另配专属客户经理，处理定制路由与批量设备问题。
